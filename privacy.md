# Privacy policy - channel tools

Last updated: November 19, 2026

channel tools is a private app used only by the owner of the YouTube channels Somehow Alive, Ifonomics HQ and Deep Knowledge Quiz.

## What data it accesses
With the owner's authorization through Google OAuth, it reads public comments, video details and YouTube Analytics reports for those channels, and posts replies or holds comments for review on those channels.

## How data is used and stored
The data is used only to help the channel owner manage comments and understand channel performance. It is stored in the owner's private GitHub repository and is not sold, shared with third parties, or used for advertising.

## Google API Services
channel tools' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access
Access can be revoked at any time at https://myaccount.google.com/permissions.
